# Carpeta de Documentos Gestionados (Sandbox Seguro)

Esta carpeta es el directorio seguro asignado para la aplicación y el agente.
El agente y la agenda tienen permisos controlados para:
- Indexar y buscar contenidos (PDFs, Word, imágenes, notas).
- Renombrar y organizar en subcarpetas (por proyecto, temática o año).
- Asociar archivos a tareas y eventos del calendario.

> **Seguridad**: El agente tiene restringido el acceso estrictamente a este directorio y sus subdirectorios para proteger el resto de tu equipo y el código fuente.
